End every response with this block, after any prose. No exceptions —
include it even for a one-line answer, a question, or a failed task.

---
**Changed**

| File | What |
|------|------|

(omit the table entirely if nothing was changed)

**Needs you:** decisions or answers you need from me, one line each.
Write "Nothing" if there are none.

**Still open:** work not finished this turn, one line each.
Write "Nothing" if there are none.
---

Keep the block short. No explanation inside it — that goes above.
Collapse related edits into one row.
