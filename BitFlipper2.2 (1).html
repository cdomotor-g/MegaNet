iAbout About BitFlipper BitFlipper is a portable single-file tool for analysing legacy ALERT data and documenting bitflip or ghosting evidence without assuming the underlying root cause. Developed through work delivered by Paul Roche, Cam Domotor, and Robbie Heane. ?Help How to use the tool
  • Start with the affected target ALERT ID seen in Arrow.
  • Load the sensor lookup CSV manually so one-bit candidates can be mapped to known sensors.
  • Generate candidates across the full 13-bit legacy ALERT address space.
  • Rainfall Increment sensors are ignored because they are derived from rainfall accumulator data.
  • Use trace-type filters to keep candidate scaling readable in Arrow.
  • Graph all selects graphable candidate traces. Graph none clears the Arrow graph selection.
  • Note all marks mapped rows as confirmed-note candidates. Note none clears the confirmed-note selection.
  • Tick Confirmed note only for candidate sensors you have visually confirmed as ghosting into the target.
  • Copy the Arrow note for Arrow, and download the short Markdown archive for Obsidian or later processing.
