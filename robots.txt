# Everything a visitor can see, a crawler may read. That is not indifference:
# a categorisation feed decides what this site is by fetching it, and a name it
# cannot classify is a name a filtering proxy denies. This file and /about.html
# exist so there is an answer to find. See docs/floodwarning-net.md.

# a crawler walking it is slowed rather than served the network in a burst.
# Listed before the Disallow below, for the parsers that take the first match.
